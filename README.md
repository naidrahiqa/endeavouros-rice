# EndeavourOS Rice & Dotfiles

Konfigurasi dotfiles & ricing sistem EndeavourOS oleh **naidrahiqa**.

## 📁 Struktur Direktori
- `.config/` : Konfigurasi aplikasi (KDE Plasma, terminal, fastfetch, dll)
- `scripts/` : Helper scripts

## 🚀 Cara Pakai
```bash
cd ~/dotfiles
git add .
git commit -m "update rice"
git push origin main
```
